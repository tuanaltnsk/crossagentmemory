The concept

Memory that moves with the agent network.

Cross-agent memory describes an infrastructure layer that lets autonomous AI agents preserve, retrieve, and share useful context across tasks, tools, sessions, and specialized agent roles.

As multi-agent systems become more capable, the ability to maintain continuity between agents may become as important as reasoning itself. The name directly expresses that category.
